## 概要
趣味で作成したSKK風のキーボードアプリです。

(四角い)車輪の再発明。

## 使用したサードパーティ製の素材
- アイコン : composablehorizons/compose-icons (Licensed under MIT License)
- 絵文字のデータ : Fantantonio/Emoji-List-Unicode

## 仕様
### ショートカットキー一覧
#### CTRL + key
- k : キーボードの切り替え
- j : 日本語モード
- e : 絵文字入力画面
- n : テンキー
- a : Select All
- x : Cut
- c : Copy
- v : Paste

#### 日本語入力中
- q : カタカナ
- CTRL + q : 半角カタカナ
- l : 半角英数
- L : 全角英数
- x : 前の変換候補
- / : abbreviationモード

### 辞書
設定画面から、SKKの辞書ファイルを読み込んで使用できます。

エンコード : EUC-JPもしくはUTF-8 (それ以外だった場合はエラーになります。)

## 今後、実装したい機能
#### 日本語入力中
- Q : カーソルに位置以降を見出し文字列にする
- X : エントリの削除
#### abbrev
- CTRL + q : 全角英数
#### その他、全体
- 再帰的な辞書登録
- カタカナモード中は、ひらがなに変換してから辞書を検索する
- 見出し語の補完
- 閉じ括弧の自動入力
